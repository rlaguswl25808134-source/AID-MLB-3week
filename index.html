03 — 3-1 Practice

k-최근접 이웃 회귀

가장 가까운 k마리의 부리 높이를 평균합니다. 분류와 거의 같고, 타깃을 다수결이 아니라 평균으로 정한다는 점만 다릅니다.

k

이웃을 찾고, 평균한다

예측하려는 샘플에서 가장 가까운 k개를 고르고, 그 샘플들의 타깃값을 평균해 예측값으로 씁니다.

k = 3 → (6.4 + 6.3 + 6.2) / 3

R²

결정계수로 평가한다

회귀에서는 정확도를 셀 수 없습니다. 대신 타깃의 분산 대비 설명된 분산을 보는 결정계수를 씁니다.

1에 가까울수록 좋고, 0은 평균 수준

MAE

오차를 크기로 읽는다

평균 절댓값 오차는 타깃과 예측의 차이를 절댓값으로 평균합니다. 숫자가 그대로 오차 크기가 됩니다.

0.16 → 평균 0.16만큼 틀림

R² = 1 − Σ (타깃 − 예측)²Σ (타깃 − 평균)²
분자 → 남은 오차 · 분모 → 타깃 자체의 흩어짐

예측이 타깃과 똑같아지면 분자가 0이라 R² = 1. 분모보다 분자가 커지면 음수도 나올 수 있습니다.

k를 바꾸면 예측 곡선이 어떻게 변할까

슬라이더를 움직이면 이웃 수 k와 예측 지점이 바뀝니다. 점수는 브라우저에서 직접 계산합니다.

Reading

k는 모델의 복잡도 손잡이

k가 작으면 가까운 몇 마리에만 반응해 훈련 세트의 국지적인 패턴을 그대로 따라갑니다. k가 크면 멀리 있는 샘플까지 평균에 넣어 곡선이 완만해집니다.

교재에서는 k = 5일 때 테스트 점수가 훈련 점수보다 높아 과소적합 신호가 보였습니다. 우리 데이터에서는 k = 5에서도 훈련 점수가 더 높아, 그 신호가 나타나지 않았습니다.

관찰. k를 1에서 10까지 바꿔도 테스트 R²가 0.968–0.982 사이에서만 움직입니다. 모델 복잡도보다 어떤 특성을 넣었는지가 성능을 더 크게 좌우한다는 뜻입니다.

Overfitting

과대적합

훈련 세트에는 아주 잘 맞지만 테스트 세트에서는 점수가 크게 떨어지는 상태. 훈련 데이터의 우연한 잡음까지 외운 경우입니다.

해결: 모델을 단순하게. KNN에서는 k를 늘립니다.

Underfitting

과소적합

모델이 너무 단순해 훈련 세트조차 제대로 설명하지 못하는 상태. 훈련 점수와 테스트 점수가 모두 낮게 나옵니다.

해결: 모델을 복잡하게. KNN에서는 k를 줄입니다.

KNN의 한계, 선형 회귀와 다항 회귀

훈련 데이터 범위를 벗어나면 KNN은 더 이상 커지지 않습니다. 직선을 학습하면 범위 밖도 예측할 수 있지만, 이번 데이터에서는 선이 아래로 내려갑니다.

훈련 데이터의 최대 길이는 15.5입니다. 그보다 큰 값은 모두 가장 가까운 이웃의 평균으로 수렴합니다.

knn.predict([[30.0]]) → [2.8]

직선은 범위 밖도 말한다

선형 회귀는 기울기와 절편을 학습해, 훈련 범위 밖도 같은 기울기로 계속 예측합니다.

Why negative?

왜 높이가 음수로 나올까

우리 데이터는 길이가 길수록 부리 높이가 낮아지는 역방향 경향을 보입니다. 큰 부리 무리의 높이가 2.7–3.3으로 작은 부리 무리(5.6–6.9)보다 낮기 때문입니다.

그래서 직선을 오른쪽으로 연장하면 높이가 계속 내려가고, 30.0에서는 물리적으로 불가능한 음수가 됩니다.

교재의 농어 데이터는 반대로 길이와 무게가 함께 커져서, 같은 코드로 50cm 농어의 무게를 1,242g으로 예측했습니다.

핵심. 모델의 예측이 말이 되는지는 숫자 하나가 아니라 데이터의 범위와 방향을 함께 봐야 판단할 수 있습니다.

05 — 3-3 Concept

특성 공학과 규제

3-3은 코드 실습 없이 개념만 정리했습니다. 아래 수치는 교재의 농어 데이터 기준 결과입니다.

실습 없음 · 개념 정리
3D

다중 회귀

특성이 여러 개인 선형 회귀. 특성 1개는 직선, 2개는 평면, 그 이상은 고차원 초평면을 학습합니다.

무게 = a·길이 + b·높이 + c·두께 + d

FE

특성 공학

기존 특성을 제곱하거나 서로 곱해 새로운 특성을 만들어내는 작업. 모델은 같은 선형 회귀지만 표현력이 달라집니다.

길이 × 높이, 길이², 두께² …

PF

PolynomialFeatures

특성 조합을 자동으로 만들어 주는 변환기. fit으로 조합을 준비하고 transform으로 변환합니다.

특성 3개 · 2차 → 9개
5차 → 55개

SS

StandardScaler

규제를 공정하게 걸려면 특성의 스케일을 맞춰야 합니다. 훈련 세트의 평균·표준편차로 테스트 세트까지 변환합니다.

z = (x − mean) / std

λ

규제

모델이 훈련 세트를 과도하게 외우지 못하도록 계수 크기를 줄입니다. 과대적합을 누르고 일반화를 돕습니다.

55개 특성 · 42개 샘플 → 과대적합 위험

R / L

릿지와 라쏘

릿지는 계수 제곱(L2)을, 라쏘는 절댓값(L1)을 규제합니다. 라쏘는 계수를 0으로 만들어 특성 선택 효과도 냅니다.

릿지 55개 중 0개 제거
라쏘 α=10 → 40개가 0

Hyperparameter

alpha는 사람이 정한다

alpha는 모델이 학습하는 값이 아니라, 우리가 미리 지정하는 하이퍼파라미터입니다. 크면 규제가 세져 계수가 더 줄고 과소적합 쪽으로, 작으면 선형 회귀에 가까워져 과대적합 쪽으로 갑니다.

적절한 값은 훈련 점수와 테스트 점수의 그래프를 그려, 두 선이 가장 가깝고 테스트 점수가 가장 높은 지점에서 고릅니다. 교재에서는 릿지 0.1, 라쏘 10이 선택되었습니다.

alpha에 따른 R² 변화 (개념도)

왼쪽은 과대적합, 오른쪽은 과소적합.

다음에 실습한다면. 판다스로 농어 CSV를 읽고 → PolynomialFeatures(degree=5)로 55개 특성을 만들고 → StandardScaler로 스케일을 맞춘 뒤 → 릿지·라쏘의 alpha를 로그 스케일로 훑는 순서. 3-3의 코드 흐름은 이 네 단계로 요약됩니다.

1

교재는 단조 증가

농어는 길이가 길수록 무게가 커집니다. 직선 하나로도 방향이 맞기 때문에 선형 회귀의 R²가 0.82까지 나옵니다.

2

우리는 두 덩어리

8–10 구간과 12–15 구간이 끊겨 있고, 큰 부리 쪽 높이가 오히려 낮습니다. 길이 하나로는 높이를 설명하기 어렵습니다.

3

그래서 특성의 문제

k를 바꿔도 점수 변화가 작습니다. 모델 복잡도보다 어떤 특성을 넣는지가 중요하다는 것을 데이터가 보여 줍니다.

07 — Glossary

개념 사전

이번 장에서 계속 나온 말들만 한 줄로 정리했습니다.

회귀 (regression)

임의의 수치를 예측하는 지도 학습. 타깃이 클래스가 아니라 연속값입니다.

분류 (classification)

샘플을 몇 개의 클래스 중 하나로 나누는 문제. 2-2의 핀치부리새 분류가 여기에 해당합니다.

k-최근접 이웃

가장 가까운 k개 샘플을 참고하는 알고리즘. 분류는 다수결, 회귀는 평균을 씁니다.

결정계수 R²

회귀 성능 지표. 1에 가까울수록 좋고, 0은 평균 수준, 음수면 평균보다 못합니다.

MAE

평균 절댓값 오차. 예측이 평균적으로 얼마나 틀렸는지를 타깃과 같은 단위로 보여 줍니다.

과대적합

훈련 세트에만 지나치게 잘 맞아, 새 데이터에서 성능이 떨어지는 상태.

과소적합

모델이 너무 단순해 훈련 세트조차 충분히 설명하지 못하는 상태.

모델 파라미터

모델이 데이터에서 학습한 값. 선형 회귀의 coef_, intercept_가 대표적입니다.

하이퍼파라미터

학습되지 않고 사람이 지정하는 값. KNN의 k, 릿지·라쏘의 alpha.

다중 회귀

특성이 여러 개인 선형 회귀. 특성이 늘수록 표현력이 커집니다.

특성 공학

기존 특성을 조합해 새로운 특성을 만드는 작업. 제곱·곱·비율 등이 있습니다.

규제

계수 크기를 줄여 과대적합을 억제하는 장치. 릿지(L2)와 라쏘(L1)가 있습니다.

08 — Code

실습 코드 다시 보기

노트북에서 핵심만 추린 코드입니다. 오른쪽 위 버튼으로 복사할 수 있습니다.

3-1_knn_regression.py 
# 1. 부리 길이 → 부리 높이 (49마리)
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsRegressor
from sklearn.metrics import mean_absolute_error

beak_length = np.array([8.2, 8.5, 8.7, 9.0, 9.1, 9.3, # … 49개
                        12.5, 13.0, 13.4, 13.8, 14.0, 14.3, 14.5, 14.8, 15.0, 15.3])
beak_height = np.array([5.8, 6.1, 5.9, 6.3, 6.0, 6.5, # … 49개
                        3.2, 3.0, 3.3, 2.9, 3.1, 2.8, 3.2, 2.7, 3.0, 2.9])

# 2. 훈련 36 / 테스트 13
train_input, test_input, train_target, test_target = train_test_split(
    beak_length, beak_height, random_state=42)

# 3. 사이킷런은 2차원 입력을 요구
train_input = train_input.reshape(-1, 1)
test_input = test_input.reshape(-1, 1)

# 4. k=5 이웃의 타깃 평균으로 예측
knr = KNeighborsRegressor()
knr.fit(train_input, train_target)
print(knr.score(test_input, test_target))                     # 0.9817
print(mean_absolute_error(test_target, knr.predict(test_input)))  # 0.1615

# 5. k를 줄이면 모델이 복잡해진다
knr.n_neighbors = 3
knr.fit(train_input, train_target)
print(knr.score(train_input, train_target))                  # 0.9874
print(knr.score(test_input, test_target))                    # 0.9800
3-2_linear_polynomial.py 
from sklearn.linear_model import LinearRegression

# KNN은 훈련 범위(최대 15.5) 밖을 모른다
knr = KNeighborsRegressor(n_neighbors=3).fit(train_input, train_target)
print(knr.predict([[30.0]]))        # [2.8]  ← 마지막 이웃 평균

# 선형 회귀: 직선 하나
lr = LinearRegression().fit(train_input, train_target)
print(lr.predict([[30.0]]))        # [-6.46]
print(lr.coef_, lr.intercept_)    # [-0.6069] 11.7460
print(lr.score(train_input, train_target), lr.score(test_input, test_target))
# 0.8297 0.7235

# 다항 회귀: 길이² 열을 추가해 2차 곡선을 학습
train_poly = np.column_stack((train_input ** 2, train_input))
test_poly = np.column_stack((test_input ** 2, test_input))

lr = LinearRegression().fit(train_poly, train_target)
print(lr.predict([[30**2, 30]]))  # [-30.94]
print(lr.coef_, lr.intercept_)    # [-0.0743, 1.1265] 2.0916
print(lr.score(train_poly, train_target))  # 0.8551
print(lr.score(test_poly, test_target))    # 0.7745
2-2_preprocessing.py 
from sklearn.neighbors import KNeighborsClassifier

# 두 특성을 하나의 2차원 배열로
bird_data = np.column_stack((beak_length, beak_height))
bird_target = np.concatenate((np.ones(35), np.zeros(14)))

# 클래스 비율을 유지하며 분할
train_input, test_input, train_target, test_target = train_test_split(
    bird_data, bird_target, stratify=bird_target, random_state=42)

# 훈련 세트 기준으로 표준화 (테스트에도 같은 mean/std)
mean = np.mean(train_input, axis=0)
std = np.std(train_input, axis=0)
train_scaled = (train_input - mean) / std
test_scaled = (test_input - mean) / std

kn = KNeighborsClassifier().fit(train_scaled, train_target)
print(kn.score(test_scaled, test_target))  # 1.0

# 새 샘플도 같은 기준으로 변환해야 한다
new = ([11.5, 4.0] - mean) / std
print(kn.predict([new]))                   # [0.]

09 — Check

확인 문제

교재의 확인 문제와 이번 실습에서 헷갈리기 쉬운 지점을 골랐습니다. 보기를 누르면 정답과 해설이 나옵니다.

Q1k-최근접 이웃 회귀는 새로운 샘플의 타깃을 어떻게 예측할까요?

분류는 다수결, 회귀는 평균입니다. 타깃이 클래스가 아니라 연속값이기 때문입니다.

Q2다음 중 과대적합을 가장 잘 설명한 것은?

훈련 세트에만 지나치게 맞은 상태입니다. 3-2의 다항 5차 모델(훈련 1.0, 테스트 −144.4)이 전형적인 예입니다.

Q3선형 회귀 모델이 찾은 방정식의 계수를 무엇이라고 부르나요?

모델이 데이터에서 학습한 값을 모델 파라미터라고 합니다. coef_와 intercept_에 저장됩니다.

Q4사이킷런에서 다항 회귀 모델을 훈련할 수 있는 클래스는?

제곱 항을 특성으로 추가한 뒤에도 LinearRegression을 그대로 씁니다. 다항식도 계수에 대해서는 선형이기 때문입니다.

Q5릿지와 라쏘의 차이로 옳은 것은?

릿지는 계수 제곱(L2), 라쏘는 절댓값(L1)을 규제합니다. 라쏘는 계수를 완전히 0으로 만들어 특성 선택 효과를 냅니다.
