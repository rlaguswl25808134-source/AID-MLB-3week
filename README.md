## 수치

노트북과 같은 분할(`random_state=42`)을 브라우저에서 다시 계산합니다.

- KNN k=5: 훈련 0.9879 / 테스트 0.9817 / MAE 0.1615, 길이 10.0 → 6.62
- KNN k=3: 0.9874 / 0.9800 · k=1: 0.9898 / 0.9677 · k=10: 0.9843 / 0.9791
- 선형: 0.8297 / 0.7235, coef −0.6069, intercept 11.746, 길이 30.0 → −6.46
- 다항(2차): 0.8551 / 0.7745, coef [−0.0743, 1.1265], intercept 2.092, 30.0 → −30.94

거리가 같은 이웃이 생기면 sklearn의 선택 순서에 따라 소수점 넷째 자리가 0.0001 정도 달라질 수 있습니다.
