# 혼공머신 2-2 ~ 3-3 손코딩 정리

『혼자 공부하는 머신러닝 + 딥러닝』 2-2와 3장을 공부한 기록입니다.
2-2에서 만든 **핀치부리새(부리 길이 · 높이)** 데이터를 그대로 가져와, 3장에서는 **부리 길이 → 부리 높이 회귀**로 질문을 바꿉니다.
2-2 · 3-1 · 3-2는 직접 손코딩했고, 3-3은 개념 중심으로 정리했습니다.

## 구성

| 절 | 내용 |
| --- | --- |
| 2-2 | 데이터 준비, train_test_split · stratify, KNN 분류, 표준화와 거리 |
| 3-1 | KNN 회귀, reshape, R²와 MAE, k 값 바꾸기 |
| 3-2 | KNN의 외삽 한계, 선형 회귀, 다항 회귀, 세 모델 비교 |
| 3-3 | 특성 공학, 과대적합, 릿지 · 라쏘 (교재 개념, 농어 데이터) |

## 수치

2-2

- 분할: 49마리 → 훈련 36 / 테스트 13
- stratify 없이: 테스트 13개 중 1이 3개 / stratify 사용: 4개
- KNN 분류 정확도 1.0, `predict([[11.5, 4.0]])` → 0
- 이웃 5개까지의 거리 1.2806, 1.8028, 2.0248, 2.4187, 2.6571
- 훈련 세트 평균 [10.708, 5.364], 표준편차 [2.204, 1.513]

3-1

- KNN 회귀 k=5: 훈련 0.9879 / 테스트 0.9817, MAE 0.1615
- k=3: 훈련 0.9874 / 테스트 0.9800

3-2

- KNN k=3: 10.0cm → 6.7 (이웃 3마리 평균), 30.0cm → 2.8
- 선형: 0.8297 / 0.7235, coef −0.6069, intercept 11.746, 30.0cm → −6.46
- 다항(2차): 0.8551 / 0.7745, coef [−0.0743, 1.1265], intercept 2.092, 30.0cm → −30.94

3-3의 숫자는 교재의 농어 데이터 기준입니다.
2차(9개 특성) 0.9903 / 0.9715, 5차(55개 특성) 1.0000 / −144.41,
릿지 α=1 0.9896 / 0.9791, 릿지 α=0.1 0.9904 / 0.9828,
라쏘 α=1 0.9898 / 0.9801, 라쏘 α=10 0.9888 / 0.9824 (55개 중 40개 계수가 0).
